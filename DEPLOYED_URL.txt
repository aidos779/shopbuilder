Deployment URL

Fill this after deploying on https://dashboard.deployrocks.com.

FRONTEND_URL=
API_URL=
SWAGGER_URL=

Required DeployRocks environment variables:
- DATABASE_URL
- POSTGRES_PASSWORD
- REDIS_HOST
- REDIS_PORT
- JWT_SECRET
- API_URL=<public backend URL, no trailing slash>
- ALLOWED_ORIGINS=<public frontend URL, no wildcard>
- EMAIL_HOST
- EMAIL_PORT
- EMAIL_USER
- EMAIL_PASS
- EMAIL_FROM
- EMAIL_TEST_TO
- FRONTEND_URL
- REQUIRE_EMAIL_VERIFICATION=true

Pre-defense deployment checks:
1. Open FRONTEND_URL.
2. Open API_URL/ and confirm `{ "status": "ok", "message": "ShopBuilder API running" }`.
3. Open API_URL/health and confirm status is ok.
4. Open API_URL/docs and confirm Swagger loads.
5. Confirm the frontend API endpoint field is set to API_URL.
6. Register/login and confirm browser requests go to API_URL, not localhost.
7. Confirm backend logs show `ShopBuilder API listening on http://0.0.0.0:3000`.
8. Confirm DeployRocks/Dokku detects the frontend web listener from `80:80`.
9. Confirm worker logs show email, webhook, abandoned-cart, and subscription workers started.
